Fusion AI - Demo Host Page

This page hosts the embeddable widget to demonstrate a real-world integration.

How this works

The floating chat button in the bottom-right corner is injected entirely by widget.js. It renders inside a Shadow DOM, so this page's aggressive .button class and global resets cannot leak into it (and its styles can't leak out either).

Before you test

1. Copy .env.example to .env and fill in FUSION_AI_WEBHOOK_URL / KIE_AI_API_KEY.
2. Run npm install then npm start.
3. Open this page via http://localhost:3001/index.html.

Try it

Click the chat bubble in the bottom-right corner to start a conversation.
